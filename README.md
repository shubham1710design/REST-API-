# Quora‑Style REST API
A simple REST API that allows users to create, read, update, and delete (CRUD) posts, similar to a Quora post system. Built with Node.js, Express.js, CSS and EJS

# Features
- Create Post – Add a new post with title and content.
- View Post – Fetch all posts or see details of a single post.
- Edit Post – Update an existing post.
- Delete Post – Remove a post permanently.

API Endpoints
Method	 Endpoint	    Description
POST	/api/posts	    Create a new post
GET	    /api/posts	    Get all posts
GET	    /api/posts/:id	Get post by ID
PUT	    /api/posts/:id	Update post by ID
DELETE	/api/posts/:id	Delete post by ID
